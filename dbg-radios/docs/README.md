# Program Artifacts (`docs/`)

Documentation and reporting artifacts for the PIN local-control program.

## Artifact Inventory

- `pin_local_control_optimization.md`
  - Purpose: mathematical framing for local PIN control and constraints.
  - Primary source: maintained manually.

- `pin_optimal_control_experiment.md`
  - Purpose: program-level runbook for reproducing the PIN optimal-control demo.
  - Technical companion docs: `../radio-sim/docs/pin_controller_api.md`, `../radio-sim/docs/pin_optimal_control_experiment.md`.

- `pin_demo_metrics.json`
  - Purpose: machine-readable A/B metrics payload for figures/tables.
  - Generated by: `python3 radio-sim/experiments/pin_csma_demo.py`

- `pin_demo_results.md`
  - Purpose: human-readable interpretation of the demo metrics.
  - Updated from: `pin_demo_metrics.json` and figures in `figures/pin_demo/`.

- `figures/pin_demo/*.png`
  - Purpose: visualization set for aggregate, per-seed, and mechanism analysis.
  - Generated by: `MPLCONFIGDIR=/tmp/mpl python3 radio-sim/experiments/generate_pin_demo_visuals.py`

- `pin_local_control_results_deck.pptx`
  - Purpose: compact briefing deck.
  - Generated by: `python3 radio-sim/experiments/build_pin_demo_deck.py`

- `pin_one_slide.tex`, `exec_summary.tex`, `optimization.tex`
  - Purpose: LaTeX sources for summary/report artifacts.

- `pin_one_slide.pdf`
  - Purpose: rendered one-slide summary.

## Rebuild Sequence

From repository root:

```bash
python3 radio-sim/experiments/pin_csma_demo.py
MPLCONFIGDIR=/tmp/mpl python3 radio-sim/experiments/generate_pin_demo_visuals.py
python3 radio-sim/experiments/build_pin_demo_deck.py
```
